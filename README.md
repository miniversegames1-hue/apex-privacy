# Apex privacy website

Nine-language privacy policy and support for Apex. Canonical URL: https://miniversegames1-hue.github.io/apex-privacy/privacy/

Public repository: https://github.com/miniversegames1-hue/apex-privacy

Copy this directory’s contents into the public site repository root. Enable GitHub Pages for that root; preserve `.nojekyll`. No build step or dependencies. No analytics, cookies, localStorage, external fonts or scripts.

`privacy/?lang=en` selects a complete policy. Supported values: en, tr, de, es, fr, it, pt-BR, ja, ko. A valid query wins over browser language; otherwise the first supported browser language is used, then English. Unknown query values are safely ignored. With JavaScript disabled all nine policies remain readable and language navigation anchors remain available. The root page provides nine policy and nine support links. Policy date: 2026-10-03. Support added: 2026-10-04.

Translation copy is complete for all nine languages, but has not been reviewed by native legal translators. Recheck app facts whenever behavior changes. Private app audit notes belong outside this public payload.

Support URL: https://miniversegames1-hue.github.io/apex-privacy/support/
